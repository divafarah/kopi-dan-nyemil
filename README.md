# ☕ Kopi dan Nyemil
Aplikasi **Kopi dan Nyemil** merupakan aplikasi pemesanan makanan dan minuman berbasis Android yang dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS).
Aplikasi ini memiliki tampilan bernuansa pastel dengan perpaduan warna strawberry pink, matcha green, dan cream yang memberikan kesan modern, elegan, dan nyaman digunakan.

## ✨ Fitur Aplikasi
1. **Splash / Welcome** – Halaman pembuka aplikasi.
2. **Sign Up** – Pilihan untuk melakukan registrasi atau login.
3. **Register** – Pendaftaran akun pengguna.
4. **Login** – Masuk menggunakan username dan password.
5. **Home** – Menampilkan daftar makanan dan minuman.
6. **Profile** – Melihat dan mengubah nama pengguna.
7. **Alamat Pengiriman** – Mengisi informasi penerima dan alamat.
8. **Konfirmasi Pesanan** – Menampilkan ringkasan pesanan setelah pemesanan berhasil.

## 🛠️ Teknologi yang Digunakan
- Android Studio
- Kotlin
- XML
- Android SDK
- SharedPreferences untuk penyimpanan data lokal sederhana
- Git dan GitHub

## ▶️ Cara Menjalankan Aplikasi
1. Clone repository ini:
   `git clone https://github.com/divafarah/kopi-dan-nyemil.git`
2. Buka project menggunakan Android Studio.
3. Tunggu proses Gradle Sync sampai selesai.
4. Hubungkan emulator atau perangkat Android.
5. Klik tombol **Run** untuk menjalankan aplikasi.
